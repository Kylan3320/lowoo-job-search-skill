# 牛客

- 从牛客「简历」进入简历服务。可尝试 `https://www.zhiyeapp.com/cv/edit`，入口变化时从当前导航定位。上传按钮与预览链接相邻时先确认目标。点击无法打开选择器时，可聚焦实际上传控件后按 Enter。
- 仅在确需上传本轮目标附件时，先从正式在线简历读取解析可能改写的现值，重点看联系方式、教育、工作和项目。在本轮上下文保留恢复所需的原值。
- 上传后从「附件简历管理」核对目标版本。仅上传附件时关闭「同步简历」。关闭或取消解析也可能发生自动写入，因此每次实际上传后立即比对可能受影响的字段。仅恢复这次被解析误改且原值可证实的字段，按工具规则回写并从正式页面读回。原值无法确认时报告具体字段。
- 解析将项目误建成工作经历时，可隐藏误建卡。核对误建卡显示「取消隐藏」且正确项目仍在。编辑正文时检查独立富文本框，防止下一栏内容串入。
