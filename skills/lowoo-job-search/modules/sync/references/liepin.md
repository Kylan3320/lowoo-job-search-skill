# 猎聘

- 从已登录页面进入个人简历，常用入口为 `https://c.liepin.com/resume/edit`。入口变化时从站内个人简历导航定位。
- 「附件简历」加号 →「上传附件简历」→ 上传区 → Windows 文件选择器。在正式附件区核对版本。本轮包含在线履历时，从解析弹窗的「立即查看」逐项确认，可以用中文版本辅助填表。
- 匹配现有经历用「更新并继续」，确认是新经历时用「保存并继续」。解析把改名项目识别成新增时，回原项目卡编辑。核对实习和公司屏蔽的预选值。项目表单可分别有概述、职责、业绩；按实际栏目拆分。在校经历位于原教育记录的编辑表单。
- 「个人作品」上传真实项目演示图，格式和大小按当前提示。替换时先核对新图及审核状态。新图待审或被拒时保留原图，用户明确要求先移除时按工具规则处理。需要替代图时使用符合提示的另一张公开素材。删除后核对剩余缩略图。
