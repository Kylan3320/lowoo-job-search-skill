# 领英（LinkedIn）

- 附件在「Jobs → Preferences → Resumes and application data」管理。在正式列表核对本轮目标语言和版本的正式附件，沿用已有共享范围。仅更新附件时完成附件流程即可。
- 更新在线档案时，从「Profile language」确认本轮目标语言档案。需要切换时按本轮范围迁移并更新继承的栏目，删除旧语言版本按工具规则处理。旧链接打不开时从「Me → View profile」进入。About 等富文本先全选清空，输入后读回。
- 添加技能和语言能力时，在英文界面搜索并点选标准英文候选。切换界面后，从正式档案核对已保存的词条。语言名称需要迁移时可在原记录重新选英文并保留等级。有可点击的关联标签时，优先用标签操作复选框或开关。
- 技能名称锁定时，先添加已确认的英文项，恢复原有经历和项目关联，并换掉 About 的 Top skills 引用。英文项核对成功后，再按工具规则处理旧项。领英提示语言替换会移除旧技能背书。[领英技能背书说明](https://www.linkedin.com/help/linkedin/answer/a565106?lang=en-US)。
- 提交前按本轮范围核对「Notify network」和「Follow this skill」的状态。Featured 优先使用公开作品链接。链接有效但预览失败且无法保存时，可上传已确认可公开的演示图，配英文标题与说明，并在「Contact info → Website」提供可点击的作品入口。浏览器上传媒体时先监听文件选择器，再点上传控件。
- 从正式栏目核对本轮改动。语言看名称和等级，技能看标准词条及关联，迁移后还要看 About、Experience 和 Projects 的引用。Featured 核对媒体与顺序，联系方式核对实际链接。保存后栏目尚未加载时，滚动或重开对应详情再核对。
