# BOSS 直聘

- 从已登录页面进入个人简历，常用入口为 `https://www.zhipin.com/web/geek/resume`。入口变化时从站内个人简历导航定位。
- 原生表单先定位焦点，粘贴后读回实际输入。日期控件确认保存值，尤其是「至今」。悬停才显示的编辑入口用当前截图或无障碍树定位。系统文件对话框确认文件名栏后输入完整路径。
- 从「附件管理」加号进入。若先显示「上传简历」，打开后选择「上传附件简历」，选文件并点「确定添加」。返回正式附件列表核对版本。占位不足时按主流程找替换入口。
- 本轮包含在线履历时，可逐项审核中文附件的同步建议。检查公司、专业、联系方式、项目归类和月份。「保存新内容」只更新预览时，继续点「保存至在线简历」。读回主简历表单的实习标记和「工作业绩」。
- 按本轮指令或适用的个人偏好处理公司屏蔽。当前经历对应公司可在表单勾选「对该公司隐藏我的简历」。指定的其他公司从「隐私设置 → 屏蔽公司」按全称匹配，再核对保存结果。
